This repository presents the work of Apostolos Stamenas, focusing on a practical implementation of the KMV EDF Structural Credit Risk Model. The objective of the project is to estimate the one-year Probability of Default (PD) for Public Power Corporation (PPC) using a structural, market-based approach to credit risk.
This implementation is intended to be educational and illustrative, bridging theoretical credit risk concepts with real-world data and empirical analysis.
